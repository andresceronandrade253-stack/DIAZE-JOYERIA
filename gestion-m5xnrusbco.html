Configuración inicial

Conecta el panel con GitHub

Se hace una sola vez. El panel guarda los cambios en este mismo repositorio, así el sitio sigue siendo gratis. Tu token queda cifrado con la contraseña que elijas abajo.

  1. Abre github.com/settings/personal-access-tokens/new e inicia sesión.
  2. Ponle un nombre al token y elige la expiración más larga que te deje.
  3. En Repository access elige Only select repositories y marca solo este repositorio.
  4. En Permissions, abre Repository permissions y pon Contents en Read and write.
  5. Pulsa Generate token, copia el token y pégalo aquí abajo.
Usa una contraseña larga y que no uses en otro sitio: protege el token.
